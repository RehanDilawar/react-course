## 🌟 Welcome to the React Course Workspace!

This repository is a structured learning path for **React.js**, containing various chapters that cover core concepts and mini-projects that apply these concepts in real-world scenarios.

Dive into the chapters to learn the theory, and explore the projects to see the code in action! ✨

## 📚 Chapters Overview

Here is a breakdown of the chapters covered in this course:

| Chapter                           | Description                                                                    | Details                   |
| :-------------------------------- | :----------------------------------------------------------------------------- | :------------------------ |
| **📁 01_first-react-app**         | Setting up the foundational React environment and creating our very first app. | 🚀 Setup & Basics         |
| **📁 02_create-react-components** | Understanding how to build robust, reusable React components.                  | 🧩 Component Architecture |
| **📁 03_bootstrap**               | Integrating Bootstrap to rapidly style and structure our applications.         | 🎨 Styling & Layout       |
| **📁 04_Fragments**               | Exploring React Fragments for a cleaner DOM structure without extraneous divs. | 🧹 Clean DOM              |
| **📁 05_Context Api**             | Mastering global state management across components with Context API.          | 🌐 State Sharing          |
| **📁 06_useReducer**              | Handling complex state logic efficiently using the `useReducer` hook.          | ⚙️ Complex State          |
| **📁 07_react-advance**           | Diving into advanced React patterns, hooks, and performance optimizations.     | 🧠 Advanced Concepts      |
| **📁 08_react-router**            | Implementing routing for single-page applications (SPAs).                      | 🗺️ Navigation             |
| **📁 09_redux**                   | Managing predictable state containers for scaleable JavaScript apps.           | 📦 Global State           |

## 🛠️ Projects Showcase

Hands-on projects built throughout the course to solidify concepts:

- **1️⃣ Todo App (Version 1, 2, 3)**: A classic task management application, refined and improved across three iterations as new concepts are introduced (from basic state to Redux/Context).
- **2️⃣ Pak Clock (Version 1 & 2)**: A beautiful clock application demonstrating real-time updates and `useEffect`.
- **3️⃣ Calculator (Version 1 & 2)**: A fully functional calculator app built with React components and robust state handling.
- **4️⃣ Social Media App**: A multi-component application showcasing complex data feeds, likes, and user interactions.
- **5️⃣ Myntra Clone**: A comprehensive e-commerce clone featuring product listings, shopping cart management, and routing! 🛒👕

## 💡 How to Run any Project/Chapter

1. Navigate to the desired folder:
   ```bash
   cd <folder_name>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
