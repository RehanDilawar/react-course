## 📖 About This Project

This is the flagship project of the course! The Myntra Clone is a comprehensive e-commerce application that ties everything together. In this project, you navigate seamlessly through pages, manage a global cart, and render dynamic product listings.

### 🌟 Project Highlights:

- **React Router**: Implementing multi-page navigation (Home, Men, Women, Cart) without page refreshes.
- **Redux / Redux Toolkit**: Utilizing advanced global state management to handle the `cart` data across completely separated components.
- **Product Listing Page (PLP)**: Dynamically rendering complex product cards from data arrays.
- **Cart Interactions**: Adding to cart, removing items, and calculating the final price/summary dynamically.
