## 📖 About This Project

Welcome to the ultimate Todo App! In this version, we solve the dreaded "prop drilling" problem that surfaced in Version 2. By leveraging context or reducer architectures, we decouple our state from deeply nested props.

### 🌟 Project Highlights:

- **Global State / Reducer**: Managing the todo array more robustly without passing it strictly via props.
- **Refactored Architecture**: Components are now cleaner because they grab the required data/methods directly from the state store!
- **Data Persistence (Bonus)**: Expanding on the basic add/delete loops.
