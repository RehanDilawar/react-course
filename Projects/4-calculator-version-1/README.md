## 📖 About This Project

Math meets UI! This project involves designing the interface for a standard calculator application. This is a critical exercise in grid layouts, CSS styling, and array mapping for button generation.

### 🌟 Project Highlights:

- **CSS Grid/Flexbox**: Organizing numerical and operator buttons beautifully.
- **Array Mapping**: Instead of manually hardcoding 15+ buttons, we map over an array of operators and numbers to generate buttons dynamically!
- **Display Component**: Preparing an input/display field for the eventual math logic.
