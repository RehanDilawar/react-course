## 📖 About This Project

Our calculator is no longer just a pretty face! In this version, we breathe life into the UI by connecting the buttons to mathematical logic.

### 🌟 Project Highlights:

- **State Integration**: Using `useState` to track the current input string on the calculator.
- **Button Click Handlers**: Updating the state string dynamically when numbers or operators are pressed.
- **Evaluating Expressions**: Properly calculating the result upon pressing `=` (and safely handling potential invalid mathematical strings).
- **Clear Logic**: Clearing the board with the `C` button.
